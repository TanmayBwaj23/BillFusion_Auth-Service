# Railway Deployment Troubleshooting

## ❌ **Issue: Healthcheck Failed**

Your deployment is failing because the `/health` endpoint isn't responding. Here's how to fix it:

---

## 🔍 **Root Causes**

### **1. Missing Environment Variables** (Most Common)

Railway needs these environment variables set:

```bash
# REQUIRED - App will crash without these
SECRET_KEY=<32+ character secret>
JWT_SECRET_KEY=<32+ character secret>
DATABASE_URL=<auto-generated by Railway PostgreSQL>
```

### **2. Database Not Connected**

The app tries to connect to PostgreSQL on startup. If the database isn't ready or `DATABASE_URL` isn't set, it fails.

### **3. Redis Not Available**

The app tries to connect to Redis on startup. If Redis isn't added or `REDIS_URL` isn't set, it might fail.

---

## ✅ **Solution Steps**

### **Step 1: Check Environment Variables**

1. Go to Railway Dashboard → Your Service → Variables
2. Verify these are set:

```bash
# Required
SECRET_KEY=your-secret-key-here
JWT_SECRET_KEY=your-jwt-secret-here

# Auto-generated (should already exist)
DATABASE_URL=postgresql://...
REDIS_URL=redis://...

# Application settings
ENVIRONMENT=production
DEBUG=false
```

### **Step 2: Generate Secrets**

If `SECRET_KEY` or `JWT_SECRET_KEY` are missing:

```bash
# Generate secure secrets (32+ characters)
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Add them to Railway Variables.

### **Step 3: Verify Database is Added**

1. Railway Dashboard → Your Project
2. Check if PostgreSQL service exists
3. If not: Click "New" → "Database" → "Add PostgreSQL"
4. Railway auto-creates `DATABASE_URL` variable

### **Step 4: Verify Redis is Added**

1. Railway Dashboard → Your Project
2. Check if Redis service exists
3. If not: Click "New" → "Database" → "Add Redis"
4. Railway auto-creates `REDIS_URL` variable

### **Step 5: Check Service Logs**

1. Railway Dashboard → Your Service → Deployments
2. Click on the failed deployment
3. View logs to see the exact error

Common errors:
```
ValueError: Required setting SECRET_KEY is not configured
```
→ Add SECRET_KEY to variables

```
sqlalchemy.exc.OperationalError: could not connect to server
```
→ DATABASE_URL is wrong or PostgreSQL isn't running

```
redis.exceptions.ConnectionError
```
→ REDIS_URL is wrong or Redis isn't running

---

## 🚀 **Quick Fix: Redeploy**

After setting all variables:

1. Railway Dashboard → Your Service
2. Click "Deploy" → "Redeploy"
3. Wait 2-3 minutes
4. Check if healthcheck passes

## 🆘 **Still Not Working?**

### **Check Logs for Specific Error:**

```bash
# Via Railway CLI
railway logs

# Look for:
- "ValueError: Required setting X is not configured"
- "Database connection failed"
- "Redis connection failed"
- Any Python tracebacks
```

### **Common Issues:**

**1. Port Binding Error:**
```
Error: Address already in use
```
→ Railway sets `$PORT` automatically, make sure your start command uses it:
```bash
uvicorn app.main:app --host 0.0.0.0 --port $PORT
```

**2. Module Not Found:**
```
ModuleNotFoundError: No module named 'X'
```
→ Missing dependency in `requirements.txt`

**3. Database Migration Error:**
```
alembic.util.exc.CommandError
```
→ Run migrations manually:
```bash
railway run alembic upgrade head
```
